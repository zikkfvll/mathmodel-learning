# 个人数学建模论文 LaTeX 模板

从现有比赛论文提取的可复用结构与版式，包含四问示例、空白图表位置和七页 [模板样张](模板样张.pdf)。这是个人模板，使用前需核对当届官方格式；模板中的说明和占位内容需要替换。

1. 复制整个目录到新项目。
2. 修改 `config.tex` 中的题名、队号、题号和开关。
3. 在 `sections/` 填写各章及各问；问数变化时同步调整摘要与问题分析。
4. 使用 XeLaTeX 编译 `main.tex` 两遍，再检查最终页面。Overleaf 也选择 XeLaTeX。

完整字体、编号和编译说明见 [使用说明](使用说明.md)。不需原比赛的数据、图件或字体文件，也不会继承原比赛的科学结论。

第三方类文件与本项目版式的来源见 [NOTICE](NOTICE.md) 和 [提取记录](SOURCE_AND_FORMAT.json)。本次公开整理未重新编译；样张来自既有模板验证。
