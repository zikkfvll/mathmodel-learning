# 文献与资料索引

本库保存引用线索与学习记录，不上传下载的第三方论文全文。

- 本次比赛的正式参考文献见 [论文 LaTeX 正文](../competitions/2026-mathorcup-b/paper/main.tex) 末尾的文献列表，可用 DOI 定向查原始来源。
- 数据产品、资料身份和分发依据见 [数据来源与许可](../competitions/2026-mathorcup-b/reproduction/数据来源与许可.txt) 及比赛目录中保留的许可文件。
- [个人论文模板](../templates/paper-latex/README.md) 是组织和排版参考，不能提供新比赛的事实或参考文献。

今后阅读记录按“具体问题—来源—实际读到的内容—适用条件—采用或放弃理由”整理。科学期刊与会议、竞赛获奖论文分别搜索，核实年份、分区或奖项后再标注，不凭仓库标题推定质量。期望每问学习约20篇，可按时间和相关性调整；摘要检索、全文取得与精读不得混为一谈。
