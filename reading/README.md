## 阅读记录怎样整理

围绕“具体问题—来源—实际读到的内容—适用条件—采用或放弃理由”组织笔记。科学期刊与会议、各类竞赛获奖论文分别搜索，核实年份、分区或奖项后再标注。期望每问学习约20篇，可按时间和相关性调整。

原文中的方法只有在适合题目、现有数据和验证条件时才采用。学习写法时重点看同方法段落如何定义对象、解释公式和呈现结果，用自己的事实重新组织表达。
