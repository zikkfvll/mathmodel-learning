# 工程沿革

论文按Q1环境特征、Q2局部材料临界条件、Q3条件首达预测、Q4规定入口传播的顺序逐步整合。各问依据自身冻结的计算结果写作，最后统一符号、图表引用、目录、文献与完整程序附录。

加入全部源码前，工程存在32页、附录2页的中间格式。当前[paper.pdf](paper.pdf)已包含283页源码附录，合计313页；当前[论文入口说明](README.md)和[版本记录](VERSION_RECORD.md)给出文件与页数。

原工作目录中的内部审核、编译临时文件和私人交接记录不属于本仓库的阅读入口。研究结果及其局限保存在论文、[补充分析](Q4_SUPPORTING_ANALYSES.md)与[复现目录](../reproduction/)。
