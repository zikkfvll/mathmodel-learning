软件与运行命令

详细步骤见 ../docs/reproduction.md。建议Python 3.12，按各问requirements文件安装依赖；Q4的C后端需要C99编译器，中文绘图需要可用中文字体。以下新输出目录均应此前不存在。

问题一（从q1目录运行）
python -m pip install -r requirements.txt
python -B sol.py --mode enhance --d1-csv data/d1_era5/era5_precipitation_hourly_2021_2026.csv --d0-cache results/d0_window_cache.json.gz --baseline-results results/baseline --output-dir new_run
python -B draw.py --results-dir results --output-dir new_figures

问题二（从q2目录运行）
python -m pip install -r requirements.txt
python -B sol.py --output-dir new_results
python -B draw.py --results-dir results --output-dir new_figures

问题三（从q3目录运行）
python -m pip install -r requirements.txt
python -B sol.py --data data --results results_new --workers 2
python -B draw.py --results results --output figures_new

问题四（从reproduction目录运行）
python -m pip install -r q4/requirements-lock.txt
python -B q4/code/sol.py decide --out q4_run/new_physics --inputs q4/data/local --backend c --volume 475682.8460010884 --mu .075 --gp-state q4/data/GP_STATE.json

这条命令调用新的30 m物理解并保存新证据，不使用旧缓存。发布整理核对了代码路径，没有再次运行该命令；结果以实际输出为准，数值或证据核验失败时保持unknown。
论文附录与历史材料中的cache-only命令属于原始归档环境。本库移除本机用户名后，部分文本的字节与旧哈希不同，不能使用旧缓存认证；请省略cache-entry与cache-only参数。

原始附件清理（从prepare目录运行）
python -m pip install -r requirements.txt
python -B clean_all.py --input-root "官方附件目录" --output-dir "new_cleaned_all"
python -B clean_data.py --input-root "官方附件目录" --output-dir "new_station_daily"
python -B era5/download.py
python -B route.py --output route_new.csv

全清理需要自行提供原始附件1—8。站点子入口只生成站点和日温结果；取数脚本缺少原响应时会联网获取公开数据。四问计算已带必要输入，通常可跳过数据准备。
